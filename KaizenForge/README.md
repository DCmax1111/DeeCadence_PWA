# Orbit - Polymath OS

Standalone local-first prototype for a self-improvement system built around kaizen, micro-habits, polymath range, and shame-free recovery.

## Open it

Open `index.html` in a modern browser. Data is saved in local storage.

## Current features

- Today dashboard with adaptive task groups, micro-wins, flexible lecture logging, and load softening.
- Task CRUD with tags, archive/restore, search, filters, history, templates, and smart schedules.
- Schedule types: daily, selected weekdays, every X days, monthly, seasonal, and one-off.
- Habit stack builder: attach one habit to another so the next action is obvious.
- Goal tracking with linked proof habits and weekly proof counts.
- Better bad-habit tracking with resisted/slipped status, trigger, replacement action, recovery minutes, and notes.
- Live insights from actual completions, minimum wins, resisted urges, reviews, focus sessions, and task history.
- Guided routine timer with auto-next, pause, skip, extend, and finish summary.
- Focus/creation session timer with notes and saved minutes.
- Weekly review with generated next-week suggestions.
- JSON and CSV export plus JSON import.
- Full backup export with app/version metadata.
- Local account login for this static prototype.
- Browser reminders and notifications while Orbit is open.
- Profile, text size, accent color, light/dark/system theme, and first-run onboarding guide.
- Mobile-first bottom navigation and compact mobile summary layout.

## Not included yet

PWA install support, cloud sync, subscriptions/paywalls, calendar integrations, server-backed authentication, and AI coaching are intentionally excluded for now.
