# Orbit — Polymath OS

Standalone product prototype for a self-improvement system focused on:

- micro-habit stacking instead of guilt-heavy perfectionism
- visible progress for both good habits and resisted bad habits
- weekday-specific routines plus uncertain lecture blocks
- complete task and goal creation, editing and deletion
- adaptive daily load, domain health, recovery and friction insights
- editable profile with persistent text size, accent color and light/dark/system themes
- local-first persistence with no setup required

## Open it

Open [index.html](./index.html) in a modern browser. All changes persist in local storage.

## Core idea

Instead of treating the day as pass or fail, the app makes progress legible through:

- an adaptive daily rhythm split into morning, deep-work, and evening anchors
- micro versions of each habit so the user can recover with tiny wins
- friction tracking for bad-habit resistance
- analytics for momentum, recovery, resistance wins, and consistency over time
- a required sidebar with Today, Tasks, Goals, Insights, Domains and Weekly Review views
- a breadth compass that protects polymath range without requiring every domain every day
