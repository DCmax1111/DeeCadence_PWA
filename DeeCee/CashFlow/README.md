# Cashflow Pilot

Open index.html in a modern browser or serve this folder locally. No install or external service is required.

A dark theme toggle is available in the header. This pilot is for Nigerian individuals and owner-run businesses. Each profile has a Personal or Business primary view over one shared ledger, so changing the view does not hide accounts. Enable mixed-use sorting when one account contains both personal and business activity. Transactions can be tagged as Business, Personal, Owner draw, Transfer or Needs sorting. Correcting a merchant can teach category, type and purpose for matching and future rows. The Cash Coach uses a visible chat thread with free-text questions and suggested follow-ups. It has deterministic support for greetings and help, goal and account counts, balances, current and previous periods, supported categories and merchant matches, safe-to-spend, planned cash, invoices, runway and sorting status. It answers only supported questions and does not learn new reasoning from chat. Correcting transactions teaches merchant matching. Goals allow up to three entries, one main goal, 25/50/75/100% checkpoints and a monthly-contribution simulator.

XLSX is the preferred spreadsheet import format; CSV remains supported. Choose the destination account before confirming any import; the app will not select one implicitly, and prompts you to create an account first if none exists. Recognizable headers open a preview and mapper; confirm to import. XLSX is read from the first worksheet on-device; its source row is retained and Excel dates are normalized. PDF transactions retain parsed date, time, description, signed in/out direction, amount, currency, page and transaction reference when present. The PDF reader also extracts the statement period and money-in/money-out totals. When both totals are available, it reconciles them against extracted transaction rows; a mismatch sends imported rows to review and is shown under Settings > Import ranges. Digital text PDFs are processed on-device. Scanned PDFs appear as Pending OCR; OCR is not implemented and the uploaded file is not retained. A text PDF with no safely recognized transaction rows is marked Pending format review.

The eye button in the top bar hides or reveals displayed money amounts across the app; this is a visual privacy aid, not encryption.

Cashflow now gates the ledger behind a local password, encrypts saved ledger data with AES-GCM, and supports unlock using either the password or the one-time recovery key. Existing plaintext data is left untouched until the user chooses a password, saves and confirms the recovery key, and the encrypted copy has been written successfully. The app then removes its old plaintext localStorage entry. A lock button hides the ledger and clears the in-memory app state. Users can reset a forgotten password with their recovery key and rotate that key after confirming the replacement; the prior key stays active until that confirmation is saved. JSON backups contain the encrypted envelope; CSV exports are plaintext and should be handled carefully.

The recovery key is shown once during setup. Store it separately from this device. If both password and recovery key are lost, the data cannot be recovered. The offline recovery flow does not provide online password reset or recovery-key rotation. The interactive [encryption-walkthrough.html](./encryption-walkthrough.html) remains a separate educational demo.

This remains a prototype, not a security certification or a substitute for independent security review. Browser storage encryption does not protect data while the ledger is unlocked, against malicious browser extensions or compromised devices, or against loss of both credentials. Use a current browser over HTTPS or localhost and synthetic or anonymized records. No login, account isolation, bank connection, hosted AI, cloud sync, OCR or tax calculations. Imports do not update account balances, and imported date ranges do not prove continuous coverage. Before handling customer financial data or charging generally, add independent security review, robust encrypted backup/restore, account isolation, audit and consent flows, and supported statement ingestion.
