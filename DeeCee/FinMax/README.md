# Cashflow Pilot
Open index.html in a modern browser or serve this folder on localhost. No install or external service is required.

This local pilot tests cashflow clarity for Nigerian individuals and owner-run businesses. Personal and business workspaces are separate. It supports manually entered balances, planned inflows and bills, goals, invoice status, CSV import with column mapping, duplicate skipping, automatic category suggestions, learned merchant corrections, a local rules-based helper, JSON backup/restore and CSV export.

Limits: data is stored in browser localStorage without encryption, login or cloud sync. Use synthetic or anonymized data on a private device. There is no bank connection. CSV only; no PDF/OCR/XLSX, sync or hosted AI. Imported transactions do not change balances. Import ranges are based on dated rows, not verified continuous coverage. The helper uses local rules and arithmetic.

Before handling customer financial data or charging generally, add secure authentication, encryption, account isolation, backups, audit logs, consent flows and supported statement ingestion.
