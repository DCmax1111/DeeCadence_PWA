# Cashflow Pilot

Open index.html in a modern browser or serve this folder locally. No install or external service is required.

This pilot is for Nigerian individuals and owner-run businesses. Each profile has a Personal or Business primary view over one shared ledger, so changing the view does not hide accounts. Enable mixed-use sorting when one account contains both personal and business activity. Transactions can be tagged as Business, Personal, Owner draw, Transfer or Needs sorting. Correcting a merchant can teach category, type and purpose for matching and future rows. The local Cash Coach answers questions about spending by purpose, goals, balances, runway and the review queue.

CSV files with recognizable headers import without column mapping; other layouts open a mapper. Digital text PDFs are extracted on-device without column mapping. Clear, high-confidence rows can be categorized automatically; uncertain rows wait for review. Scanned PDFs appear as Pending OCR. OCR is not implemented and the uploaded file is not retained. PDF layout recognition remains heuristic, so check imported activity.

Limits: data stays in browser localStorage without encryption, login or cloud sync. There is no bank connection or hosted AI; the coach uses local rules and arithmetic. Use synthetic or anonymized records on a private device. Imports do not update account balances, and imported date ranges do not prove continuous coverage. Tax calculations are not implemented. No OCR, XLSX or sync.

Before handling customer financial data or charging generally, add secure authentication, encryption, account isolation, backups, audit logs, consent flows and supported statement ingestion.
