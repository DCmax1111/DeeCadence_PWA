# DeeCadence Sound Sources

These sounds are used only when the matching in-app setting is enabled. Ambient
loops play only while a focus block is running.

- `block-complete.wav`: Mixkit sound effect ID 933, sourced from https://mixkit.co/free-sound-effects/notification/
- `session-complete.wav`: Mixkit sound effect ID 212, sourced from https://mixkit.co/free-sound-effects/win/
- `brown-noise.wav`, `wind.wav`: synthesized for DeeCadence with procedural noise (no external samples), 12-second seamless loops with a crossfaded seam. They may be regenerated or replaced freely.
- `rain_and_thunder.mp3`: rain-and-thunder ambience supplied for DeeCadence. Confirm distribution rights before commercial release.
- `classical_music.mp3`: classical music track supplied for DeeCadence. Confirm distribution rights before commercial release.

License reference: Mixkit Free License, https://mixkit.co/license/

Before commercial distribution or Play Store release, re-check the current Mixkit license terms and replace these files if the license changes.
